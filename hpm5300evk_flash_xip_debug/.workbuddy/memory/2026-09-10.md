# 2026-09-10

## 排查：J-Scope 中 g_ia/g_ib/g_ic 波形畸变（像方波）

**现象**：电机正常转动，J-Scope 观察三相电流波形畸变、类似方波。

**根因（已定位，代码层）**：观测链路欠采样。
- `g_ia/g_ib/g_ic` 只在 `src/app/app_monitor.c: app_monitor_update()` 里更新，
  而该函数仅由 `src/app/main.c` 的主循环 `while(1){ app_monitor_update(); bsp_delay_ms(1); }` 调用
  → 刷新率约 1 kHz（`APP_MAIN_LOOP_DELAY_MS = 1`，另有 `sens_vbus_read()` 里 20us 忙等）。
- 而电流环 / ADC 采样 / 编码器更新都在 20 kHz 的 ADC ISR（`ctrl_foc.c: isr_adc`）。
- 工程内无 SEGGER RTT 代码 → J-Scope 走 HSS 模式直接读 RAM，
  变量本身只有 1 kHz 更新率，无论 J-Scope 采多快都是 1 kHz 台阶；
  1 kHz 对几十~几百 Hz 电频率就是欠采样/混叠 → 正弦被采成方波状。

**建议改法**：把相电流观测搬到 ADC ISR（20 kHz），vbus 等慢量留在主循环。
即新增 `app_monitor_update_fast()`（只更新 g_ia/g_ib/g_ic/g_raw_u/g_raw_v），
在 `isr_adc()` 末尾调用；主循环的 `app_monitor_update()` 只保留 g_vbus。

**顺带发现（非本次现象根因，但值得修）**：
1. ADC 配的是 16bit（`BOARD_BLDC_ADC_RES_BITS = 16U`），但取值宏 `DRV_ADC_GET_12BIT` = `>>4`
   只用 12bit → 有效分辨率被砍。`APP_CURRENT_Q_REF = 0.15A` 时码值仅 ~19 LSB
   （1 LSB ≈ 8mA：3.3V/4095/20/0.005Ω），量化台阶肉眼可见。
2. B 相是重构的：硬件只采 A(ADC1)/C(ADC0)，B = -(A+C)。两路 ADC 零漂分开校准，
   若增益/偏置不一致，g_ib 会比其他两相更歪。
3. 电流环 PI（`motor.c: motor_tune_current_loop`）注释已警告公式可疑。
   按当前参数算：kp=0.311、ki=0.130，因 ki/kp 恰好 = R/L（零点对消极点），
   实际闭环带宽 = kp/L ≈ 118 rad/s ≈ **19 Hz**，而非设定的 200 Hz —— 稳定但很慢，
   不是方波的来源，但换电机参数时应一并重算。

**关键代码位置**
- 观测：`src/app/app_monitor.c`、`src/app/main.c`、`src/app/app_cfg.h`
- ISR：`src/control/ctrl_foc.c`
- 采样点：`src/driver/drv_pwm.c` cmp_config[2].cmp = 5（零矢量窗口）
- 相电流换算：`sens_analog.c` + `hpm_mcl_analog_get_value`（A 为单位）
- 板级：`boards/hpm5300evk/board.h`（E249 移植：ADC 通道重分配）
