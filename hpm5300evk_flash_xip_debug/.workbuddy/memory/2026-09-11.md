## 速度环启动"顿一下再起转" —— 定位与修复（src/bldc_foc.c）

### 关键事实：SES 工程只编译 src/bldc_foc.c
`segger_embedded_studio/bldc_foc.emProject` 里唯一的应用源文件是 `../../src/bldc_foc.c`。
`src/app/main.c` 等分层源码 **不在** SES 工程里（CMakeLists.txt 已改成分层，但 emProject / build.ninja
是旧的、没重新生成）。**改分层代码不会生效，调试阶段必须改 bldc_foc.c。**

### 根因（速度环版）
三件事叠加，都在启动瞬间：
1. 主循环里的速度斜坡斜率只有 0.05 rad/s per ms（50 rad/s 要 1 秒）→ 起步 ref≈0 → 误差≈0 → iq≈0，
   电机无转矩，只能等积分器攒到能克服静摩擦（实测/仿真约 80 ms），然后被一把拽起来 = "顿"。
2. `hpm_mcl_loop_enable()` 只做 `loop->enable = true`，**不清 PID 积分**；MCL 的 `hpm_mcl_control_pi()`
   只有 `integral += ki*err`，没有抗饱和/清零接口。
3. 速度环 PI 太软：kp=0.0074 / ki=0.0001 → ωn≈59 rad/s（9.4 Hz）、ζ≈0.55。
   且 `integral_max=100` 配 `output_max=5`，输出被削掉后积分还能攒到 100，退饱和极慢。

### 已落地的改动（src/bldc_foc.c，error 0）
- `BOARD_BLDC_SW_FOC_SPEED_LOOP_SPEED_KP/KI`: 0.0074/0.0001 → **0.02 / 0.00008**
  （Kt=1.5*p*flux=0.054 N·m/A，J=6.2e-6 → Kt/J=8710；无延迟理论整定 0.0216/2.55e-4@15Hz，
   但速度反馈过 100 Hz 四阶 IIR，等效时延约 5 ms，ki 必须退到 8e-5，否则阶跃超调 50%）
- 速度环限幅：`integral_max` 100→3、`output_max` 5→3（对齐 `physical.motor.i_max=3`；
  积分限幅压到与输出限幅一致 = 最省事的抗饱和）
- 投运前显式清零 `speed/currentq/currentd_pid_cfg.integral`
- 斜坡提速 10 倍：0.5 rad/s per ms（100 ms 到位），移出死循环、放回主循环
- ISR 里补 `speed_rad_s = motor0.encoder.result.speed;`（之前只声明没赋值，J-Scope 上恒为 0）
- 仿真结果：起转 11 ms，峰值 52.6 rad/s，超调约 6%

## 追加：上电"顿一下"的真正根因 —— 测速链路第一拍假速度尖峰

用户 J-Scope 实测：`motor0.encoder.result.speed` Min = **-27.43 rad/s（反转）**、Max = 64.23、稳态 49.90；
`g_ref_q` Min=0.043 / Max=0.578 / 稳态 0.095 A（稳态 0.09A×Kt0.054≈0.005N·m，与假设摩擦一致）。

根因链（已数值验证）：
1. `hpm_mcl_encoder_init()` 里 `memset(cal_speed.memory,0,...)` → M 法 `theta_last = 0`
2. 第一次 `hpm_mcl_encoder_process()` 算 `θ - 0`，θ增量最大 ±π
3. ÷50us → 原始假速度 **±62832 rad/s**
4. 过 encoder_iir（100Hz 四阶；冲激响应峰值 0.0248、滞后 2.2ms、4ms 衰减到 1%）→ **±1557 rad/s**
5. 速度环 4kHz 撞上 → err=-1557 → kp*err=-31 → iq 顶到 **-3A** 约 2ms → 反向踹一脚

**注意 `hpm_mcl_filter.c` 的 scale 位置**：`y` 存入 mem 的是**未乘 scale** 的原始值，scale 只乘在
返回值上（`mem.y1 = y_raw; ...; y *= scale;`）。等价于标准 biquad (1,2,1)/(1,a1,a2) 后接 scale 增益，
DC 增益 = scale*4/(1+a1+a2) = 1.0。手写仿真时如果把 scale 乘进递推里，DC 增益会错成 1.6e-5。

已加修复（bldc_foc.c，main 的 if/else 对齐分支之后）：
```
hpm_mcl_loop_disable(&motor0.loop);
board_delay_ms(20);          /* 让尖峰在滤波器里自然耗散，τ≈2.25ms */
/* 重新清三个 PI 积分 */
hpm_mcl_loop_enable(&motor0.loop);
```
更彻底的替代方案（未做）：直接 `motor0.encoder.cal_speed.m_method.theta_last = 当前θ`，
或在冲洗后把 IIR mem 一并清零。
