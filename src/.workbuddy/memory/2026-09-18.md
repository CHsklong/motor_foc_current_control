- CAN 教学讲解（用户自称新手，要求讲清 CAN 是什么/电机驱动中怎么用/代码怎么写/命令怎么写）。
  讲解结构：物理层(差分 CANH-CANL、显性 2V、隐性 0V、120 欧终端、共模 -2~+7V 故需共地)
  -> 帧结构(仅 ID/DLC/DATA 需关心，ACK 位需节点拉低否则自动重发，ID 小者优先级高)
  -> 8 字节定标原因(float 太占，故 x0.1/x0.01 压成 int16，f_to_i16 的来源)
  -> 上下行两条链路(下行事件驱动/上行 100ms 定时，遥测是判断通断最快标志)
  -> ISR 与主循环职责划分(ISR 只搬运进 8 深环形缓冲，解析与发送留给主循环)
  -> 代码五部分(init/ISR/poll/命令解析/打包小端定标)
  -> 命令字节换算(交互式计算器 widget，含负数补码)。
