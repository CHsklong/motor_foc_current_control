## 新增 S 型加减速（jerk 受限）轨迹规划器

- 新建 `src/control/traj_s_curve.h/.c`：7 段式 S 曲线。**闭式解预计算 + 每拍纯函数求值，
  没有状态机** —— 这是针对"上一版 S 曲线卡在 g_pos_step=2"的根治办法：位置只是
  "已过时间 t"的函数，不存在卡在某个中间态的可能。
- 四种形状自适应（自动判据，调用方无感）：①七段 ②五段(达amax/速度三角)
  ③四段(加速度三角) ④五段(达vmax/amax未达)。拐点判据 va=amax²/jmax、
  Dmin、Da=2·amax³/jmax²。
- 集成要点（踩坑记录）：
  1. **S 曲线不能沿用"接近限速"**：vlim=sqrt(2·POS_DECEL_MAX·|err|) 在 err 天生很小的
     S 曲线给定下会把速度给定掐死。必须换成前馈结构
     `v_cmd = v_ff + ACC_FF_TAU*a_ff + 位置外环修正`。
  2. **MCL 位置环没有前馈注入点**：position_pid 输出直接写 exec_ref.speed，
     ref_speed.enable 又是整体覆盖而非叠加。所以 S 曲线模式下
     `enable_position_loop=false`，由 ctrl_foc.c 自己按 4kHz 调 hpm_mcl_position_pid()
     后加前馈，再用 hpm_mcl_loop_set_speed() 下发；MCL 不再帮忙调
     encoder_get_abs_theta()，改为自己调。
  3. **POS_LOOP_DIV 必须是 5 不是 20**：hpm_mcl_loop_init() 里 position_ts 指针
     指向 speed_loop_ts，位置环实际 4kHz；ki 也是按 250us 整定的。
- 参数集中在 motor_params.h 末尾：SCURVE_VMAX 25 / AMAX 150 / JMAX 4000 /
  ACC_FF_TAU 0.02 / POS_CORR_MAX 6 / POS_LOOP_DIV 5。
- 回退开关：`app_cfg.h` 的 `SCURVE_ENABLE`（0=回到原阶跃给定+接近限速）。
  两条路径都做过 -fsyntax-only 检查，0 error / 0 warning。
- app_cfg 已切到 FOC_POSITION_MODE=1 + step_response_p=1（S 曲线往复演示）。
- 新增 J-Scope 探针 g_sc_t / _v_ref / _a_ref / _v_cmd / _corr / _state / _shape /
  _t_all / _vp / _move_cnt / _busy_cnt。
- 离线验证脚本 `docs/scurve_sim.py` → `docs/scurve_profile.html`：同一套公式的 Python
  复算，四种形状全部通过（终点闭合 0、起止 v/a 为 0、峰值不越限、加速度无阶跃）。
  主用例 D=12.5π：T=1.775s，tj=37.5ms，ta=204ms，tv=1.37s，vp=25rad/s。
- 构建清单：CMakeLists.txt 与 SES 的 bldc_foc.emProject 都要加 traj_s_curve.c
  （SES 工程是显式列文件的，不会自动 glob）。

## 输出原理+代码对照文档

- 新增 `docs/scurve_explained.html`（配图由 `docs/scurve_doc_fig.py` 生成，公式与
  traj_s_curve.c 逐行一致）：原理篇（梯形 vs S、七段结构、jerk→a→v→p 三次积分、
  加速段中心对称 v(ta−t)=vp−v(t) ⇒ d_acc=½·vp·ta、减速段时间反演 u=t_all−t、
  四种形状判据推导）+ 代码篇（plan/shape/eval_at/isr_tick 逐段）+ 接入篇（前馈结构、
  三个坑）+ 参数表 + 探针判读表。
- 关键数学结论（复用时直接引用）：
  · 加速段位移 d_acc = ½·vp·ta（由中心对称推出，不用积分）；
  · 段③ 用"整段减剩余"：p = d_acc − vp·u + jmax·u³/6，u = ta − t；
  · 减速段纯时间反演：p = p_end − dir·P(u)，v = dir·V(u)，a = −dir·A(u)；
  · 门槛值 va = amax²/jmax，Da = 2·amax³/jmax²，Dmin（tv=0 时的位移）。
